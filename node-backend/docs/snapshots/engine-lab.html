The maths

Reward ra = CTR × CVR × k × (pa − F) = θa × (pa − F) per impression (same margin whichever price the buyer picks: no-return is ₹30 lower and saves ≈ ₹32)
Starting beliefs come from the pooled demand model across similar products: ln q = α + β ln p, β = −3 → θa ~ Beta(n₀·θ̂, n₀·(1−θ̂)), n₀ = 2,000
a* = argmaxa: pa ≥ F θ̃a·(pa − F), θ̃a ~ Beta(sa, fa), one draw per day: that menu is live for every buyer that day; then s += kept, f += impressions − kept
Shrinkage w = n / (n + n₀): weight on SKU data vs category prior
Goal mode objective: GROWTH → ₹ profit per impression, after a volume-first launch. Holdout = similar sellers without ProfitPilot, at their own price (seller-level, so every buyer still sees one price) · ₹399.
